# Generated submission evidence

Run `python self_test.py` to regenerate synthetic edge-case predictions, three PNG verification views and `self_test_report.json`.

Run `python self_test.py --data-root data` after placing the organizer development subject folders under `data/`. That mode writes real development predictions to `development_predictions/` and replaces the verification visuals with the first three real cases.

Synthetic outputs demonstrate software behavior only. They are not substitutes for the required organizer development-set predictions.
